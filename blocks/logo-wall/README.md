# Logo Wall

Lokales Showcase-Scaffold, noch ohne fertige Beispiele. Kein zentrales CSS/JS.

## Beispiel

HTML nach `examples/`, danach `bash examples/build-manifest.sh`. Die Bühne lädt vorhandene Beispiele automatisch.

## Bildgenerierung

> Do not generate fake third-party logos. Use text placeholders or user-supplied authorized logo assets only. If a neutral placeholder is required, generate abstract non-brand geometric marks with no letters, no words, no trademarks, no watermark, isolated on transparent or neutral background.

UI-Text bleibt HTML. Original nach `assets/source/`; danach `bash assets/process-images.sh`.
