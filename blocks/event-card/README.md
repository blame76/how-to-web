# Event Card

Lokales Showcase-Scaffold, noch ohne fertige Beispiele.

## Beispiel

HTML nach `examples/`, danach `bash examples/build-manifest.sh`. Die Bühne lädt das Manifest automatisch. CSS und JS bleiben lokal.

## Bildgenerierung

> Documentary photograph of a fictional professional event or meetup, people in a realistic venue, no readable signage, no text overlay, no logos, no watermark, natural candid atmosphere, horizontal 3:2 composition, 1800px minimum.

UI-Text bleibt HTML. Original nach `assets/source/`; danach `bash assets/process-images.sh`.
