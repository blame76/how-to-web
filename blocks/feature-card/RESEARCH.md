# Feature Card – Recherche

Stand: 2026-09-26

- Eine Feature Card sollte genau eine zusammenhängende Fähigkeit oder einen Nutzen erklären.
- Rahmen und Card-Optik nicht nur dekorativ einsetzen.
- Icon oder Bild muss dieselbe Aussage unterstützen wie Text und Überschrift.
