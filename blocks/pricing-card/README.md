# Pricing Card

Lokales Showcase-Scaffold, noch ohne fertige Beispiele.

## Beispiel

HTML nach `examples/`, danach `bash examples/build-manifest.sh`. Die Bühne lädt das Manifest automatisch. CSS und JS bleiben lokal.

## Bildgenerierung

> No photographic asset is required for the canonical pricing-card example. If an illustration is later needed, generate a minimal abstract service illustration with no text, no numbers, no logos and no watermark, isolated on a neutral background, square 1:1 composition.

UI-Text bleibt HTML. Original nach `assets/source/`; danach `bash assets/process-images.sh`.
