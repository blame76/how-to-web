# Quote / Testimonial

Lokales Showcase-Scaffold, noch ohne fertige Beispiele. Kein zentrales CSS/JS.

## Beispiel

HTML nach `examples/`, dann `bash examples/build-manifest.sh`. Die Bühne lädt vorhandene Beispiele automatisch.

## Bildgenerierung

> Natural editorial portrait of a fictional customer or professional, authentic expression, neutral real-world setting, no text, no logos, no watermark, realistic photography, square 1:1 composition, 1600px minimum.

UI-Text bleibt HTML. Original nach `assets/source/`; danach `bash assets/process-images.sh`.
