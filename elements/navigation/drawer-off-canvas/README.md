# Drawer / Off-Canvas

Lokales Showcase-Scaffold, noch ohne fertige Beispiele. Kein zentrales CSS/JS.

## Beispiel

HTML nach `examples/`, danach `bash examples/build-manifest.sh`. Die Bühne lädt vorhandene Beispiele automatisch.

## Bildgenerierung

> No generated image is required. Use interface structure only. Any icon asset must be a simple original monochrome symbol with no text, logo or watermark.

UI-Text bleibt HTML. Original nach `assets/source/`; danach `bash assets/process-images.sh`.
